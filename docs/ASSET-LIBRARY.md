# 图片素材库

客户端与 `/gallery` 均支持展示标题、收藏筛选、标题/文件名/提示词搜索、名称或时间排序、卡片尺寸滑条及生成信息复制。侧栏每页 24 张，支持页码跳转；图片复制失败会明确提示使用下载，不会把链接复制当作图片附件成功。

## 数据与兼容

- 稳定 ID 由素材源 ID 和原文件名派生。修改展示标题不影响文件名、原图、下载地址或 ID；外部移动或重命名文件属于新的存储身份。
- 展示标题、收藏、标签、集合和备注写入数据根的 `data/asset-metadata.json`，使用原子写入。客户端和侧栏共用生成图的记录；侧栏读写仍受 Key 归属限制。
- 新的标准图片生成/编辑代理请求，在 `gen-images/index.json` 记录原始提示词、上游返回的改写提示词、请求参数和可识别的返回尺寸/格式/实际渲染模型。不保存参考图二进制或凭据。
- 原先缺少记录的图片、外部文件和绕过该代理直接落盘的图片不会推测生成信息，界面显示未记录。
- 卡片尺寸按浏览器及页面保存在本地；标题和收藏保存在网关，重启后仍在。
- 浏览器图片剪贴板要求安全上下文与写入权限。局域网 HTTP 或受限 WebView 可以下载原文件后添加到 Agent。

## 第二阶段：标注、WorkBuddy 交接与版本

客户端和侧栏的“标注 / 使用”打开共用编辑器。支持矩形、圈选、箭头、画笔、编号点、编号说明、整体修改要求、需要保留的内容、缩放、无标注原图对照、撤销和重做。草稿自动保存，可关闭后重新打开。

### 继续编辑

1. 客户端先选择与 WorkBuddy MCP 相同的 Key。本地素材可分配给指定 Key；已有归属的生成图片使用其原 Key。侧栏直接使用当前身份。
2. 填写要求，点击“带标注继续编辑”，再复制指令并粘贴到 WorkBuddy 当前输入框。指令包含 `edit_session_id` 和 `edit_revision`，不包含密钥。
3. WorkBuddy 调用更新后的 `generate_image`。网关从受 Key 保护的草稿中读取无标注原图快照、标注参考图和文字说明。原图始终是第一张；标注图仅用于解释位置。
4. 返回图进入生成图库，记录 `parentId` 和 `familyId`，卡片显示“新版本”。编辑器的版本记录可查看同一系列的图片。

草稿保存不会调用图片模型。复制和拖拽也不会自动发送消息。版本冲突时重新打开素材页并复制当前指令，不猜测版本号。该闭环通过网关的订阅 bridge 图片代理实现；直接在外部另行生图不会自动关联版本。

### 文件复用

- 支持复制无标注原图或标注图，下载时保留原图原始字节。
- 新桌面构建提供“准备文件拖拽”：生成只含原图、标注预览、编辑说明的文件集合，再按住拖拽按钮放到 WorkBuddy 输入框。使用系统文件拖拽，不暴露任意文件路径。拖拽票据 15 分钟内有效，过期需重新准备。
- 侧栏浏览器无系统文件拖出能力时使用图片粘贴、下载后拖入，或复制编辑指令。WorkBuddy 官方公开能力支持粘贴图片与文件拖入，但未提供可验证的“网页直接填入当前输入框”接口，因此不会显示“已加入附件”的虚假反馈。
- 系统拖拽报告放下后，仍应检查目标输入框是否显示附件。自动化已验证 Windows 原生代码编译及票据/路径约束；WorkBuddy 的实际附件接收未完成实机验收。

### 存储与范围

- 编辑草稿与原图快照位于数据根 `data/asset-edits`；原图不会被标注覆盖。坐标以 0–1 的归一化值保存，标注参考预览最长边不超过 2048。
- 每个草稿最多 100 条标注，输入原图支持 PNG/JPEG/WebP，最多 25MB、16M 像素。显示标题、备注均以纯文本展示。
- 新预览提交成功后移除旧预览，保留当前草稿。已导出的文件集合独立保存在 `cache/asset-exports`。
- 移入回收站或彻底删除回收文件不会删除已有草稿、原图快照、其他版本或外部副本；草稿清理需另行处理。
- MCP 客户端需重新加载以读取新增参数；LAN 独立 MCP 脚本和 Skill 已同步更新。

## 第三阶段：集合、批量整理、回收站和对比

客户端与侧栏素材站的“整理 / 回收站 / 对比”打开同一管理页。客户端可跨素材源浏览；侧栏只显示当前 Key 的生成图片及回收记录。

- 一张素材可加入多个集合、添加多个标签；输入名称即可创建，移除最后一张素材的归属后，空集合或标签不再显示。当前采用平面集合，不含嵌套目录。批量添加新名称并移除旧名称可调整归类。
- 支持按来源、集合、标签、收藏筛选，搜索同时覆盖标题、文件名、提示词、标签、集合和备注。单图整理可编辑备注。
- 支持逐张勾选、Shift 连选、本页全选和跨页保留选择；每次最多处理 200 项。批量增删标签、加入/移出集合、设置收藏，未填写的字段保持原值。集合和标签分别最多 20 / 32 个。
- 原有客户端、侧栏与 MCP 删除操作统一移入回收站。回收文件保存在数据根 `data/asset-trash`，不自动清空；恢复会还原原文件、生成记录及关联元数据。同名文件存在时拒绝覆盖；本地素材源被删除或目录变更时需先恢复原配置。云端记录支持整理，需导入本地后才能使用回收功能。
- 回收站支持单张或批量恢复、彻底删除；批量操作逐项报告失败，保留失败项选择。彻底删除需要确认且无法撤销。
- 移入回收站与彻底删除的确认框是页面内浮层（支持确定 / 取消 / Esc / 点击遮罩），不依赖浏览器原生 `confirm`。Agent 侧边浏览器、沙箱 iframe 会静默吞掉原生对话框，若回退到原生调用会表现为「点了没反应」。
- 同系列素材可选择关联版本；也可勾选任意两张进行并排或滑动叠加对比，支持交换左右。原图完整适配容器，不同尺寸不做拉伸，对比不提供像素差分结论。
