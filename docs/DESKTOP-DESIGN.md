# 工作台设计规范 v1

适用于桌面工作台、启动与维护状态、独立素材站及安装向导。任务完成状态仍以 `DESKTOP-TASKS.md` 为准。

## 导航与职责

| 分组 | 页面 | 内容 |
|---|---|---|
| 工作区 | 概览 | 模型代理、当前账号、用量与快捷入口 |
| 工作区 | 账号管理 | 添加与管理账号、额度、连接诊断 |
| 工作区 | 图片素材 | 生成图库、目录与云端来源、预览、复制、下载和删除 |
| 工作区 | 模型能力 | 模型目录与客户端接入 |
| 开发接入 | API Key | 创建、范围、复制、启停与删除 |
| 开发接入 | 调用日志 | 业务调用、状态筛选与运行日志 |
| 管理 | 服务与诊断 | 本机服务启停、进行中任务、诊断与退出 |
| 管理 | 数据与备份 | 首次工作空间、迁移、历史检查与恢复 |
| 管理 | 设置 | 连接配置 / 应用偏好；系统自启动与后台行为 |

同一时刻只展示一个工作台视图。日常业务与本机管理使用相同导航、标题和窗口尺寸。两种来源保留原有权限边界；页面切换不授予业务页面本机管理权限。服务停止时管理页仍可用。

## 视觉基础

- 主色：浅色 `#7053c1`，深色 `#bca8f5`。浅紫只用于选中、轻背景和焦点；常规区域采用中性色。
- 风险操作使用玫红语义色，警告使用琥珀色；成功采用紫色文字和明确状态，不恢复绿色品牌。
- 侧栏 232px，折叠 64px，900px 以下自动折叠。正文使用清晰的系统无衬线字体，数字和地址使用等宽字体。
- 间距遵循 4/8px 基础节奏，常用间距 12/16/24px；控件、卡片和弹窗使用一致的边界、圆角与焦点样式。
- 原创品牌图形结合代码括号、连接与伙伴节点意象，不表示官方关联。SVG 为源文件，导航线条统一；PNG、ICO、ICNS 和安装器图片由仓库脚本生成。

## 内容与交互

- 页面首先展示状态、数据和下一步操作。实现细节、教程与背景说明放在折叠帮助中，不占据主工作区。
- 错误、数据过期、权限不足和危险操作的后果必须明确显示；不能用隐藏样式代替错误处理。
- 本机服务存活与模型代理运行是不同状态，分别命名。未知显示等待或无法读取，不显示成功、停止或关闭。
- 账号页不重复提供概览中已有的模型代理启停；高级诊断按需展开。
- 日志每页 30 项，API Key 每页 20 项，图库每页 24 项。筛选、切换来源或数据减少后，当前页必须有效。
- 弹窗支持键盘焦点、Esc 和返回焦点。强制结束与中断任务前再次确认；数据迁移及恢复保留原有检查和停止确认。

## 验证要求

宽屏与窄屏、深浅主题、空态与填充态、加载失败与操作反馈均需验证。原生导航还需检查单一可见视图、页面实际内容、自启动与系统状态同步、会话和权限拒绝、Node 身份及正常退出。浏览器模拟不替代桌面原生验证；Windows 结果不替代 WKWebView 与签名发行验收。
