# v1.14.0

- 图片素材库新增展示标题、收藏、搜索、卡片大小滑条、分页与生成提示词/参数复制，客户端与 Agent 侧栏共用元数据。
- 共用图片标注编辑器支持框选、圈选、箭头、画笔、编号说明、撤销重做和自动保存草稿；通过 MCP 将原图、标注和要求交给 WorkBuddy 继续编辑，生成结果保留父版本关系。
- 新增集合、标签、备注及批量整理，支持跨页选择、组合筛选、回收站恢复和同名保护；任意两张或同系列版本可并排、滑动叠加对比。原有删除入口统一进入回收站。
- 客户端接入集中提供 API、MCP、Skill 的验证与配置复制，更新局域网接入页、独立 MCP 脚本和图片 Skill。
- 完善图片编辑、蒙版、扩图及返回尺寸/透明度核验；未记录的信息不推测，实际返回与请求不符时明确报告。
- 桌面设置新增软件更新，使用固定公钥校验安装包签名；安装前等待任务完成并保留独立数据目录中的账号、配置和图片。

Windows x64 桌面预览版，未配置 Windows Authenticode 代码签名。安装包及在线更新清单提供独立的更新签名验证；提供 Setup、免安装 ZIP、签名、更新清单及 SHA-256 校验文件。旧版需手动安装一次新版以启用更新器。

已完成独立测试图库中的标注/编辑闭环、批量归类、搜索、删除恢复、版本对比及窄侧栏验收。WorkBuddy 原生跨窗口拖拽接收、跨版本安装重启尚未完成实机验收；侧栏可使用图片复制、下载或编辑指令交接。
