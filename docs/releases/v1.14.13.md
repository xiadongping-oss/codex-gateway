# v1.14.13

- 客户端接入的 Agent 配置分为「首次配置」「更新 Skill / MCP」「更换 API Key」三种模式；网页接入页同步提供三个独立 Prompt 入口。
- 修复更新 Prompt 可能覆盖用户 Key 的问题：普通更新不解密、不包含页面所选 Key，保留目标客户端现有凭据，匹配原连接并检查更新前后 keyId 一致。未找到连接或原凭据失效时停止说明，不借用其他用户 Key。
- 显式更换 Key 时，选择新 Key 后生成专用 Prompt：先只读验证新身份，备份后仅替换指定连接凭据，保留其他 MCP、设备信息、Skill 与模型设置。明确报告文件配置和当前会话是否均已切换。
- 明确提示：换 Key 会切换个人图库，旧图片不会自动迁移；素材站需要使用同一新 Key。仅修改 Key 名称不会切换用户身份。

升级后在「客户端接入」选择对应模式，再复制新的 Prompt。普通更新可提供给连接同一网关的不同用户；首次配置及更换 Key 的 Prompt 含所选凭据，仅发给对应用户。已经误换凭据的客户端仍需先恢复正确 Key，升级不会自动恢复已被覆盖的客户端配置。

Windows x64 桌面预览版，提供安装包、便携 ZIP、在线更新签名和 SHA-256 校验文件。安装包未配置 Windows Authenticode 代码签名。
