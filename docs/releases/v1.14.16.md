# v1.14.16

- 修复账号额度把登录凭据里的「订阅周期快照」误判为订阅失效：`chatgpt_subscription_active_until` 只是登录时的订阅周期日，自动续费不会及时刷新（实测 11-07 刚签发的凭据里仍写着 11-05 的旧周期），日期已过时不再显示红色「订阅已过期」。
- 改为中性的「到期日待核验」提示，并说明该日期不代表续费状态或账号可用性；账号能否使用以连接检测和上游实时响应为准。凭据快照过期但上游限流头正常返回时，周额度等实时数据照常展示。
- 手动登记的到期日现在优先于凭据快照，在「编辑」里保存后界面立即生效；到期日改按本地日历日比较，到期当天不再被算成已过期。
- 新增订阅到期展示契约测试与 3 条单测回归，`npm run test:unit` 共 345 项全部通过。

本次提供 Windows x64 安装包、便携 ZIP、在线更新签名和 SHA-256 校验清单。
