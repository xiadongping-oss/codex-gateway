# v1.14.14

本版集中修复局域网共享场景下「更换 API Key」引发的一连串问题，并补齐整理站的确认交互。

- **配置 Prompt 不再被误转发**：更新 / 换 Key Prompt 写入「范围限制」，目标为 `127.0.0.1` / `localhost` 时明确禁止转发给其他设备，仅端口相同不算地址匹配；`/setup` 由服务端注入网关本机规范地址，共享端口的回环页选择「网关本机用户」会被拒绝并给出正确入口。
- **素材站换 Key 可用**：移除原生 `confirm()`（内嵌浏览器与沙箱 iframe 会静默返回 false，表现为「点了没反应」），改为一步式门禁态；新 Key 先经 `GET /v1/gen-images/me` 只读验证，通过才写入，失败保留原 Key；新增「取消，继续使用原 Key」，删除确认改为页面内浮层。
- **文本模型与出图不再使用不同 Key**：换 Key Prompt 现在枚举对话模型配置、MCP 连接、记录脚本、素材站凭据四处，统一替换为同一新 Key，并用模型侧与 MCP 侧的 Key 分别请求 `/v1/gen-images/me` 比对 `keyId`；不一致时明确报告「模型侧仍是旧 Key」，不得声称完成。首次配置与更新 Prompt 也加入只读一致性检查。
- **新增「完全卸载」模式**：无需 Key、先备份，逐项移除指向本网关的模型配置、MCP 连接、Skill 与记录，保留其他客户端配置与网关图片，并逐项报告结果；网页 `/setup` 与桌面「客户端接入」均提供入口。适用于历史配置已分叉时清干净再一次装回。
- **后台「图片素材」支持按来源用户筛选**：生成图索引原本已记录 `keyId` / `keyName`，现由 `/__gw/assets` 透出 `ownerKeyId` / `ownerKeyName`，新增「按来源用户筛选」下拉与卡片归属显示；Key 改名或删除后仍按原 `keyId` 分组，旧图归入「无归属（旧图）」。
- **整理站批量操作可用**：「移入回收站」「彻底删除」改为页面内确认浮层（确定 / 取消 / Esc / 点遮罩），不再依赖浏览器原生对话框；切换视图会取消未决确认。

## 升级后要做的事

局域网用户若曾出现「文本模型与出图使用不同 Key」：推荐在 `http://<网关地址>:<共享端口>/setup` 复制「完全卸载」Prompt 交给 Agent，重新加载客户端后，由宿主在「客户端接入」选择该用户的新 Key 生成「首次配置」Prompt 一次装回；或直接发新版「更换 API Key」Prompt，它会同步两处凭据并自检。随后在 `/gallery` 用同一新 Key 登录。旧图片不会自动迁移或删除，宿主可在后台按来源用户筛出后取回。

桌面版用户升级到本版后，后台「按来源用户筛选」需重启应用才会完整加载归属数据。

Windows x64 桌面预览版，提供安装包、便携 ZIP、在线更新签名和 SHA-256 校验文件。安装包未配置 Windows Authenticode 代码签名。
