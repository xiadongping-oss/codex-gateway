# v1.14.12

- API Key 名称旁新增编辑按钮，支持修改名称、保存和取消。改名保留原密钥、用户 ID、授权范围、调用统计和已有图片归属；名称立即持久化，重启后保留。仅管理员可修改。
- 修复旧 stdio MCP 工具在网关主机上配置用户 Key 后仍读取全量图库的问题：带 Key 的图库查询统一通过个人图库 API，失效 Key 不回退读取磁盘。同步更新随包客户端与可下载的局域网客户端。
- 补充多用户并发回归：两个不同 Key 交错完成聊天、HTTP 生图及 MCP 生图请求，验证响应对应、图片归属和跨用户查看、下载、删除限制。

每位用户应使用独立 API Key，并在个人素材站 `/gallery` 输入自己的 Key。多人共用同一个 Key 会共用图库；宿主机管理员的「图片素材」页面按设计可查看全量图片。改名不会把一个 Key 拆成多个用户，也不会迁移历史图片。

验证：338 项单元测试、49 项前端测试，以及并发隔离、图库和客户端兼容性回归通过。并发验证使用本地模拟上游，未替代各客户端的实机验收。

升级后重启网关。使用旧 stdio MCP 的客户端需更新对应客户端脚本并重新连接；HTTP MCP 服务端随网关升级。

Windows x64 桌面预览版，提供安装包、便携 ZIP、在线更新签名和 SHA-256 校验文件。安装包未配置 Windows Authenticode 代码签名。
