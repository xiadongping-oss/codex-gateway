# v1.14.1

- 修复自动更新直接覆盖程序目录、可能保留旧版废弃资源的问题：自动更新、被动和静默安装先运行已注册的旧版卸载器，再安装新版。
- 保留安装器原有的运行检测和关闭能力。交互安装可以确认由安装器关闭旧程序，无需先手动退出；软件内更新仍会先等待已有任务完成并保存数据。
- 旧卸载器缺失、返回失败或没有移除旧主程序时停止安装，避免继续混合覆盖。正常卸载后保留的安装路径设置不会阻止重新安装。
- 升级保留独立数据目录、已有自启动配置及快捷方式；不递归删除程序目录或用户自行添加的文件。

Windows x64 桌面预览版，提供安装包、免安装 ZIP、在线更新签名、更新清单及 SHA-256 校验文件。未配置 Windows Authenticode 代码签名。
